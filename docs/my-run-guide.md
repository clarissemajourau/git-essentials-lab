# My Run Guide

## Prerequisites

- Git 2.23 or newer
- JDK 17 or newer
- Python 3.9 or newer

## Run the demo

```
python3 run.py demo
```


## What the demo does

The demo compiles the small Java library application and runs it with a
fixed date (2026-09-01). It prints the student and faculty loan limits,
searches the catalog, borrows the book "Git Essentials" for Alex, shows
the due date and the return fee, and prints the number of active loans
after the book is returned.
